# 모바일 PWA 작업 안내

PC 웹(`/web`) 우상단 **모바일 버전** 버튼의 기존 링크(`/`)로 들어갑니다. `/web` 페이지 파일은 수정하지 않았습니다.

| 주소 | 모바일 기능 |
| --- | --- |
| `/` | 모바일 홈, 장소 유형, 프로필 바로가기, 앱 설치 안내 |
| `/explore` | 지역 선택, 지도·목록, 검색·유형·강아지 조건 필터, 장소 상세·전화·공유·찜 |
| `/favorites` | 지역을 넘나드는 찜 목록 |
| `/dog` | 여러 강아지 등록·수정·관리, 비교 대상 선택 |
| `/start` | 첫 강아지 등록 튜토리얼 |
| `/start/character?dog=아이디` | 견종 캐릭터 세부 꾸미기·저장 |
| `/record` | 강원 시군구 방문 스탬프·방문 날짜 |

모바일 라우트는 `src/routes/(mobile)`, 모바일 화면·컴포넌트는 `src/lib/mobile`과 `src/lib/components/mobile`에 있습니다. `(mobile)`은 SvelteKit 라우트 그룹이므로 실제 URL에는 표시되지 않습니다. 모바일 CSS는 이 그룹에서만 불러옵니다.

프로필·찜·캐릭터는 기존 `WebStore`와 서버 API를 사용합니다. 로그인 전에는 같은 브라우저의 웹과 모바일이 같은 로컬 저장 키를 사용합니다. 로그인 후에는 기존 계정 저장 방식을 따릅니다. 방문 스탬프는 기존 웹과 마찬가지로 브라우저 저장소에 남으며, 다른 기기로 자동 동기화되지 않습니다.

기존 웹 프로필·튜토리얼·캐릭터·스탬프 화면을 모바일 전용 사본으로 분리해 경로와 레이아웃을 조정했습니다. 이 사본은 `src/lib/mobile/screens`에 있으며, 웹 팀의 화면 변경을 자동으로 가져오지는 않습니다. 모바일 지도는 `src/lib/mobile/MapView.svelte`에 있으며, 마커를 갱신할 때 SDK의 오래된 이벤트 핸들이 남지 않도록 기본 버튼 이벤트를 사용합니다. 도메인 판정·저장 로직·지도 SDK 로더·데이터 API는 계속 공유합니다.

모바일 라우트 그룹은 클라이언트에서 처음 렌더링해 브라우저에 저장된 프로필·캐릭터와 첫 화면이 일치하게 했습니다. `/web`의 서버 렌더링은 그대로입니다.

## 실행 및 검증

```sh
npm ci
npm run dev
npm run check
npm test
npm run build
npm run preview -- --host localhost --port 4173
```

일반 화면 작업은 `http://localhost:5173/`에서 합니다. 서비스 워커와 설치 동작은 프로덕션 빌드의 미리보기 또는 HTTPS 배포에서 확인합니다. 실제 휴대폰은 HTTPS 배포 주소를 사용해야 합니다. 휴대폰의 `localhost`는 개발 PC 주소가 아닙니다. 네이버 지도·카카오 로그인도 해당 테스트 출처가 제공자 설정에 등록되어 있어야 합니다.

PWA 공통 설정은 기존 `static/manifest.webmanifest`, `src/service-worker.ts`를 보완했습니다. 설치 시 수천 장의 장소 사진과 영상 전체를 내려받지 않고 앱 코드와 최소 자산을 캐시합니다. 방문한 정적 미디어는 최대 80개까지 보관합니다. 계정 HTML·인증 API·동반 규정 응답·외부 지도는 저장하지 않습니다. 오프라인으로 새 화면을 열면 연결 안내를 표시하며, 지도와 최신 규정 조회에는 인터넷이 필요합니다.

새 서비스 워커가 대기하면 모바일에서 ‘새 버전이 준비됐어요’를 안내합니다. 사용자가 새로 열기를 선택해야 갱신하므로 작성 중인 내용을 갑자기 새로고침하지 않습니다.

## 확인한 동작

2026-09-20 로컬 검증: `npm run check` 오류·경고 0개, `npm test` 14개 파일·121개 테스트 통과, `npm run build` 성공. 360px·390px 브라우저 화면에서 장소 검색·상세·뒤로가기, 강아지 등록, 캐릭터 저장·설정 복원, 찜·스탬프의 새로고침 후 유지를 확인했습니다. 테스트 데이터는 별도 출처인 `localhost:4173`에 저장했습니다.

기존 `/web/explore`의 모바일 버튼에서 `/`로 이동하는 동작, 새 서비스 워커 적용, 미리보기 서버를 종료한 뒤 오프라인 안내가 표시되는 동작도 확인했습니다. 실제 휴대폰의 홈 화면 설치와 카카오 계정 로그인은 이번 로컬 검증에 포함하지 않았습니다.
