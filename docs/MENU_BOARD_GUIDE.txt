댕브리웨어 가게 메뉴판 (사진·설명·가격)
작성 기준: 2026-09-19

1. 왜 따로 모으나

화면의 '대표 메뉴'는 원래 공공데이터(강원 반려동물 동반관광 API의 '이용요금' 칸)를 쓴다.
그 칸에는 메뉴 이름만 줄줄이 들어 있고, 사진도 설명도 없다. 가격은 열에 하나 정도만 적혀 있다.
  "- 아메리카노 7,000원- 카페라떼 8,000원- 햄치즈토스트 5.000원"
네이버 플레이스처럼 사진 + 설명 + 가격으로 보여 주려면 그만큼의 값이 더 필요해서,
가게 메뉴판을 옮겨 둔 파일을 따로 두었다: src/lib/data/placeMenus.json

메뉴판이 있는 가게는 그 메뉴판만 보여 주고, 없는 가게는 지금처럼 공공데이터 문구를 보여 준다.
둘을 섞지 않는다. 반씩 섞이면 화면 아래의 '어디서 온 값인지' 한 줄을 정직하게 쓸 수 없다.

2. 파일 모양

{
  "schemaVersion": 1,
  "places": {
    "region-chuncheon-f27db59bfe4ab32597de": {
      "source": "네이버 플레이스",
      "sourceUrl": "https://map.naver.com/p/entry/place/1234567890",
      "collectedAt": "2026-09-19",
      "items": [
        {
          "name": "씨월드호떡",
          "price": "2,500원",
          "description": "꿀 + 견과류 로 속이 꽉찬 삼맛대표매뉴",
          "photo": "/menus/region-chuncheon-f27db59bfe4ab32597de-1.webp",
          "signature": true
        },
        { "name": "아메리카노", "price": "5,000원", "group": "음료" }
      ]
    }
  }
}

- 열쇠(장소 id)는 `npm run data:regions` 목록이나 화면 URL에서 확인한다. 강릉은 'gw-194' 꼴이다.
- name 말고는 전부 없어도 된다. 없는 칸은 화면에서 그 줄을 통째로 뺀다. 지어내지 않는다.
  · photo 가 없으면 사진 칸 없이 글자만 나온다 (빈 네모를 남기지 않는다).
  · price 가 없으면 가격 줄이 없다. '가격 문의' 같은 말을 대신 채우지 않는다.
- signature: true 면 이름 위에 '대표' 딱지가 붙는다.
- group 은 '[음료]' 처럼 구분을 지을 때만. 같은 group 끼리 이어서 적으면 한 묶음이 된다.
- source 는 화면 아래 한 줄에 그대로 나온다. 어디서 옮겼는지 반드시 적는다.

3. 사진 넣기

photo 에 남의 서버 주소를 그대로 걸지 않는다. 언제 사라질지 모르고, 사진이 있는 그 페이지의
이용 약관에 걸린다. 장소 대표 사진과 같은 방식으로, 받아서 우리 static/ 아래에 두고 쓴다.

  1) placeMenus.json 의 photo 칸에 원본 사진 주소(http/https)를 임시로 적는다.
  2) npm install --no-save sharp
  3) node scripts/fetch-menu-photos.mjs
     → static/menus/<장소id>-<번호>.webp (가로 480px) 로 저장하고,
       placeMenus.json 의 photo 를 '/menus/...' 로 바꿔 준다. 이미 받은 사진은 건너뛴다.

올릴 수 있는 사진인지(가게가 직접 준 사진인지, 옮겨도 되는 출처인지)는 넣기 전에 확인한다.

4. 자동으로 못 긁는 이유

네이버 플레이스는 스크립트로 부르면 캡차를 돌려주고, 약관에서도 자동 수집을 막는다.
그래서 메뉴판은 사람이 보고 옮겨 적는다. 한 가게에 5~10줄이면 충분하고, 대표 메뉴 위주로
몇 곳만 채워도 화면은 그 가게만 사진으로 보여 주고 나머지는 지금 모습 그대로 나온다.

5. 연결된 곳

- 고르기: src/lib/data/menuBoards.ts (장소 id → 메뉴판)
- 합치기: src/lib/domain/place.ts 의 placeMenu() (메뉴판 있으면 그쪽, 없으면 공공데이터)
- 화면: src/lib/components/MenuBoard.svelte (웹 상세 / 모바일 시트가 같이 쓴다)
