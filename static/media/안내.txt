# 메인 랜딩 산책 영상 자리

메인 화면(/web) 상단 16:9 칸에 들어갈 영상·GIF 를 이 폴더에 넣습니다.
(강아지와 주인이 산책하는 영상)

## 넣는 법

1. 파일을 이 폴더에 둡니다. 이름 뒤에 날짜를 붙여 주세요.
   - walk-YYYY-MM-DD.mp4 : 영상 본편 (권장: H.264 mp4, 16:9, 소리 없이 재생됨)
   - walk-poster.jpg     : 영상이 뜨기 전 보여줄 첫 화면 (선택)
2. src/routes/web/+page.svelte 의 walkVideo 경로를 새 파일 이름으로 바꿉니다.
3. 예전 영상 파일은 지웁니다.

## 왜 이름을 매번 바꾸나요

서비스 워커가 static/ 파일을 경로 단위로 캐시합니다. 같은 이름(walk.mp4)으로 덮어쓰면
이미 방문한 적 있는 브라우저는 예전 영상을 계속 틀어 줘요. ?v=2 같은 쿼리를 붙여도
경로가 같아서 소용이 없습니다. 이름을 바꾸는 것이 확실합니다.
(지금은 서비스 워커가 뒤에서 새로 받아 두도록 고쳐 놔서 다음 방문에는 바뀌지만,
 새로 올린 영상을 바로 보여 주려면 이름을 바꾸는 편이 안전합니다.)

GIF 를 쓸 경우에는 <video> 대신 아래처럼 바꿉니다.

  <img class="film-media" src="/media/walk.gif" alt="반려견과 산책하는 모습" />

영상이 없는 동안에는 검은 화면으로 비워둡니다.
