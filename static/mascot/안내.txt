서비스 마스코트 '댕브리' 그림.

원본: assets/댕브리_*.png (흰 배경). 여기 있는 webp 는 배경을 지운 투명 그림이라 multiply 없이 어디에나 얹을 수 있어요.
다시 만들 때: python scripts/mascot-cutout.py  (rembg 필요, 파일 머리말 참고)

- dangbri-wave.webp       댕브리_인사. 손 흔드는 인사 포즈. 720px 정사각, 발끝이 바닥선(아래 4%) — 튜토리얼 첫 화면, 캐릭터 만들기 안내
- dangbri-curious.webp    댕브리_궁금. 갸웃하는 얼굴 — 튜토리얼 입력 단계 안내
- dangbri-finish.webp     댕브리_마무리. 반짝 떠오른 얼굴 — 튜토리얼 완료 화면
- dangbri-run-1~8.webp    댕브리_달리기 시트의 8프레임. 1이 가장 멀리, 8이 가장 가까이. 480px 정사각, 발끝이 바닥선(아래 5%)에 맞춰져 있어
                          CSS 로 크기만 키우면 달려오는 원근이 살아요 — 튜토리얼 첫 화면
- dangbri-hello.webp      (예전 방식) 댕브리_인사를 흰 배경 그대로 760px 로 줄인 것. 메인(랜딩) 마무리 섹션에서 mix-blend-mode: multiply 로 씁니다.

경로가 코드에 박혀 있어요: src/lib/domain/mascot.ts
서비스 워커가 static/ 을 경로 단위로 캐시하니, 그림을 바꿀 때는 파일 이름도 같이 바꾸세요.
