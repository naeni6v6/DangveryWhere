# 🐕 DangveryWhere (댕브리웨어)

> 🚧 **Work in Progress**

## Overview

A mobile app for finding dog-friendly places on a map.
The name is a wordplay on **댕댕이 (dog)** + **Everywhere**.

## Problem

- Pet-friendly info is scattered across blogs and social media
- "Pet-friendly" is ambiguous — indoor vs. patio, size and leash rules vary
- Existing map apps have no pet-specific filters
